# Game of the Amazons

## Course: Artificial Intelligence

### Description  
The Game of the Amazons is an abstract strategy game implemented as a multi-agent system using adversarial search algorithms. The project features AI agents that use Minimax, Alpha-Beta Pruning, and ExpectiMax to make strategic decisions.

This implementation simplifies the original game to focus on core AI concepts. It is developed on a 6x6 board with one Amazon per player instead of four. Players take turns moving their Amazon (using queen-like movement) and then shooting an arrow to block a square on the board. A player loses when no legal moves are available on their turn.

### How to run the game?
1. **Clone the repository**  
```bash
git clone https://github.com/angelaangeleska/GameOfTheAmazons.git
cd GameOfTheAmazons
```

2. **Install dependencies**  
```bash
pip install -r requirements.txt
```

3. **Run the game**  
- **If you already have Jupyter Notebook open:** Simply open the `.ipynb` file and run all the cells.  
- **If Jupyter is not running yet:** Start it by running:
  ```bash
  jupyter notebook
  ```
